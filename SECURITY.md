
# Практикум 15. Перевірка безпеки

## Перевірка XSS

Перевірено можливість XSS через поле title
у каталозі настільних ігор.

Спочатку виконано окремий тест з innerHTML.
Він показав, що небезпечний HTML-код може
виконуватися, якщо вставляти введені дані
безпосередньо в HTML сторінки.

У самому каталозі назви ігор уже виводилися
безпечним способом через Vue.

Для додаткового захисту в існуючу форму
додавання гри додано перевірку назви.
Форма відхиляє символи < і > та назви
довжиною понад 100 символів.

Повторний тест показав повідомлення про
помилку. Небезпечне значення не було додано.

Також у Node.js налаштовано Content-Security-Policy.
Після ввімкнення CSP браузер заблокував
виконання тестового обробника onerror.

## Перевірка браузерних сховищ

Переглянуто localStorage та IndexedDB
через вкладку Application у DevTools.

У сховищах знаходяться дані настільних ігор
та службові позначки застосунку.

У перевірених записах не виявлено паролів,
токенів авторизації чи платіжної інформації.

## HTTP та HTTPS

Локально застосунок працює за адресою
http://127.0.0.1:3000.

Для публічного розгортання обрано
Render Web Service, який підтримує
Node.js та HTTPS.

Сервер підготовлено до використання
порту з process.env.PORT.

Публічне розгортання поки не виконувалося.

## Висновок

Перевірено XSS, браузерні сховища та
налаштування HTTP.

Додано перевірку назви гри у формі,
захисні HTTP-заголовки та підготовлено
сервер до майбутнього розгортання з HTTPS.
