
# Практикум 15. Перевірка безпеки

## XSS

Перевірено відображення назв настільних ігор.
У поточному коді назви виводяться через Vue
та textContent, а не через небезпечне innerHTML.

Для порівняння розглянуто небезпечний приклад
із innerHTML та безпечне відображення тексту.
Додано окрему форму перевірки введення.

## localStorage та IndexedDB

У localStorage зберігаються дані каталогу ігор
та службові позначки.

IndexedDB містить назви ігор, кількість гравців,
тривалість та статус колекції.

Для роботи застосунку не потрібні паролі,
токени авторизації або платіжні дані.
Такі дані не слід зберігати в localStorage.

## HTTP та HTTPS

Під час локальної розробки використовується
http://127.0.0.1:3000.

Для публічного розгортання потрібен HTTPS.
Доступ до даних через звичайний HTTP не захищає
передачу інформації від перехоплення.

У Node.js додано захисні заголовки:
Content-Security-Policy,
X-Content-Type-Options,
X-Frame-Options та Referrer-Policy.

## Висновок

Перевірено можливість XSS через назву гри,
використання браузерних сховищ та налаштування
HTTP. Безпечний текстовий вивід залишено,
а захист сервера додатково посилено.
